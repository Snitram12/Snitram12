### 👨‍💻 Sobre mim

- 🏛️ Faço parte da equipe de desenvolvimento do **SisEU**, sistema de gerenciamento dos Encontros Universitários da UFC — Campus Sobral.
- 🚀 Idealizei o **GerCon**, projeto pessoal para facilitar a gestão de escalas e outras demandas de grupos de coroinhas.
- 🎨 Participei do **InclusivaMente Matemática**, uma experiência educacional interativa em 3D.
- 🌱 Estou sempre aprendendo sobre **desenvolvimento web, APIs, bancos de dados e engenharia de software**.
